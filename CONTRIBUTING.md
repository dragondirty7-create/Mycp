# Contributing to MyCP

MyCP is at draft 0: mostly ideas, carefully written down. The most useful contributions right
now are:

- **Objections.** "This will break when…" is worth more than "looks great".
- **Studio reality.** If you mix, produce or build DAW tools, tell us where the draft doesn't
  match how sessions actually go.
- **Prior art.** OSC conventions, control-surface protocols, psychoacoustic models, anything
  MyCP should reuse instead of reinvent.

Open an issue for discussion. Proposed spec changes should explain the problem first, then
the change.

By contributing you agree your contribution is licensed under [Apache-2.0](LICENSE), the same
as the rest of the project.
